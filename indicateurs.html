Question 2 · Origine des produits

Chiffre d’affaires avec les fournisseurs de l’UE

Quel est le chiffre d’affaires total généré à ce jour avec les fournisseurs de l’Union européenne ?

Requête SQL

SELECT SUM(pr.CoutAchat * dc.Quantité * (1 - dc.[Remise (%)])) AS CA
FROM
  (((Produit AS pr
  INNER JOIN DetailCommande AS dc ON pr.RefProd = dc.[Réf produit])
  INNER JOIN Fournisseur AS f ON pr.NoFour = f.NoFour)
  INNER JOIN Pays AS pa ON f.NoPays = pa.NoPays)
WHERE pa.UE = "Membre";

Explications

  • Les tables Produit, DetailCommande, Fournisseur et Pays sont reliées par des jointures.
  • pa.UE = "Membre" garde les fournisseurs de l’Union européenne.
  • Le montant de chaque ligne combine coût d’achat, quantité et remise ; SUM() donne le total.

Résultat

IndicateurValeur

Question 3 · Santé

Chiffre d’affaires annuel desserts et boissons

Quel est le chiffre d’affaires annuel pour les catégories desserts ou boissons ?

Requête SQL

SELECT SUM(dc.Quantité * pr.CoutAchat * (1 - dc.[Remise (%)])) AS TotalGlobal
    FROM
      (((Commande AS co
      INNER JOIN DetailCommande AS dc ON co.[N° commande] = dc.[N° commande])
      INNER JOIN Produit AS pr ON dc.[Réf produit] = pr.RefProd)
      INNER JOIN Categorie AS ca ON pr.CodeCateg = ca.CodeCateg)
    WHERE YEAR(co.DateCde) = 2021
      AND ca.NomCateg IN ("Boissons", "Desserts");

Explications

  • Commande, DetailCommande, Produit et Categorie sont reliées par des jointures.
  • YEAR(co.DateCde) = 2021 limite le calcul aux ventes de 2021.
  • IN ("Boissons", "Desserts") sélectionne les deux catégories ciblées ; SUM() calcule le total.

Question 4 · Offre commerciale

Produits carnés non commandés

Nombre de produits carnés non commandés actuellement.

Requête SQL

SELECT
  COUNT(*) AS NbProduitsCarnesNonCommandes
FROM
  Produit AS pr
  INNER JOIN Categorie AS ca ON pr.CodeCateg = ca.CodeCateg
WHERE
  ca.NomCateg LIKE "Viandes"
  AND pr.RefProd NOT IN (
    SELECT
      [Réf produit]
    FROM
      DetailCommande
  );

Explications

  • Produit et Categorie sont reliées par une jointure INNER JOIN pour filtrer sur le nom de la catégorie.
  • ca.NomCateg LIKE "Viandes" permet de cibler uniquement les produits de la catégorie des viandes.
  • NOT IN (SELECT ...) exclut l'ensemble des références produits présentes dans la table DetailCommande afin de ne conserver que ceux n'ayant jamais été commandés.

Question 5 · Partenariat client

Clients pilotes et clients partenaires

A-t-on des clients pilotes d’un réseau partenaire ayant autant de commandes que les clients partenaires ?

Requête SQL

SELECT
  c1.codecli AS pilote,
  c2.codecli AS partenaire,
  (
    SELECT
      COUNT(*)
    FROM
      commande
    WHERE
      commande.codecli = c1.codecli
  ) AS nb_cmd_pilote,
  (
    SELECT
      COUNT(*)
    FROM
      commande
    WHERE
      commande.codecli = c2.codecli
  ) AS nb_cmd_partenaire
FROM
  clientele AS c1
  INNER JOIN clientele AS c2 ON c1.codeclipart = c2.codecli;

Explications

  • Une auto-jointure (INNER JOIN de clientele sur elle-même) associe chaque client "pilote" (c1) à son client "partenaire" (c2) via la clé codeclipart.
  • Deux sous-requêtes corrélées comptent respectivement le nombre total de commandes effectuées par le pilote (nb_cmd_pilote) et par son partenaire (nb_cmd_partenaire).
